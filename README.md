# Tesla Homepage Clone (Responsive Web Application)

A modern, fully responsive web clone of the Tesla homepage built using **HTML5** and **CSS3**. This project accurately replicates core sections of Tesla's web interface, featuring fluid layouts, custom media queries for mobile, tablet, and desktop viewports, video integration, and flexible carousels.

---

## 🚀 Features

* **Responsive Navigation Header:** Adapts seamlessly across screen sizes, featuring brand logos, utility icons, and a toggleable mobile menu button.
* **Hero Banner Section:** High-impact initial screen displaying featured vehicle models and clear Call-to-Action (CTA) buttons.
* **Full Self-Driving (FSD) Section:** Showcases key statistics, gradient typography, and embedded responsive video content.
* **Vehicle & Energy Carousels:** Horizontally scrollable and flexible cards highlighting popular models (Model 3, Model Y, Cybertruck, Solar Panels, Powerwall, Megapack, and Solar Roof).
* **Interactive Mini-Cards:** Custom card layouts for current offers and shareholder updates, optimized with button alignment and stacked mobile views.
* **Multi-Device Responsive Footer:** Fully visible footer links and legal notices styled gracefully across mobile, tablet, and desktop resolutions.

---

## 🛠️ Built With

* **HTML5** – Semantic document structure and layout hierarchy.
* **CSS3** – Advanced styling, Flexbox layout models, CSS variables, gradients, and custom responsive `@media` queries.
* **Google Fonts** – *Roboto* typography integration.

---

## 📱 Responsive Layout Breakdown

* **Desktop View (`≥ 1200px`):** Full-screen layout with complete horizontal navigation menus and side-by-side card arrangements.
* **Tablet View (`768px - 1199px`):** Adjusted container margins, centered mini-cards, and wrapped footer navigation links.
* **Mobile View (`< 768px`):** Stacked column views for mini-cards with full image visibility, optimized padding, and full-width touch-friendly buttons.
